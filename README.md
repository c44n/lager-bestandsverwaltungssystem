# lager-bestandsverwaltungssystem
Bestandsverwaltungssystem mit Funktionen wie Admin-Panel-Einrichtung, CRUD-funktionen für Marken, Lager, Lieferanten, Kunden und Produktkategorien, Produktmanagement, Einkaufs- und Verkaufsmanagement, Retouren, Fälligkeitsmanagement, Lagertransfers, Berichterstellung und Benutzerrollenberechtigungen, pdf Rechnungen, Produktdetails verwalten
